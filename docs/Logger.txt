5.【强制】在日志输出时，字符串变量之间的拼接使用占位符的方式。

正例：logger.debug("Processing trade with id : {} and symbol : {}", id, symbol);

6.【强制】对于 trace / debug / info 级别的日志输出，必须进行日志级别的开关判断：

正例：
// 如果判断为真，那么可以输出 trace 和 debug 级别的日志
if (logger.isDebugEnabled()) {
logger.debug("Current ID is: {} and name is: {}", id, getName());
}


9.【强制】异常信息应该包括两类信息：案发现场信息和异常堆栈信息。如果不处理，那么通过关键字
throws 往上抛出。
正例：logger.error("inputParams: {} and errorMessage: {}", 各类参数或者对象 toString(), e.getMessage(), e);

10.【强制】日志打印时禁止直接用 JSON 工具将对象转换成 String。

正例：打印日志时仅打印出业务相关属性值或者调用其对象的 toString() 方法。

2. 业务请求日志：开始 / 成功 / 失败 / 耗时

private static final Logger log = LoggerFactory.getLogger(BizService.class);

public Result doBiz(String traceId, String bizType, String bizId, Long userId, BizParam param) {
    if (log.isInfoEnabled()) {
        log.info("biz request start traceId={} bizType={} bizId={} userId={} params={}",
                traceId, bizType, bizId, userId, param == null ? null : param.toString());
    }

    long start = System.currentTimeMillis();
    try {
        Result result = doSomething(param);
        long cost = System.currentTimeMillis() - start;

        if (log.isInfoEnabled()) {
            log.info("biz request success traceId={} bizType={} bizId={} userId={} resultCode={} costMs={}",
                    traceId, bizType, bizId, userId, result.getCode(), cost);
        }
        return result;
    } catch (Exception e) {
        long cost = System.currentTimeMillis() - start;
        log.error("biz request failed traceId={} bizType={} bizId={} userId={} costMs={} error={}",
                traceId, bizType, bizId, userId, cost, e.getMessage(), e);
        throw e;
    }
}

buildSafeParams 示例思路：

private String buildSafeParams(HttpServletRequest request) {
    // 只取业务关键字段，并脱敏；禁止 JSON.toJSONString(request)
    return "orderId=" + request.getParameter("orderId")
            + ", mobile=" + desensitizeMobile(request.getParameter("mobile"));
}

private static final Logger log = LoggerFactory.getLogger(BizService.class);

public Result doBiz(String traceId, String bizType, String bizId, Long userId, BizParam param) {
    // 业务请求开始
    if (log.isInfoEnabled()) {
        log.info("业务请求开始|biz request start traceId={} bizType={} bizId={} userId={} params={}",
                traceId, bizType, bizId, userId, param == null ? null : param.toString());
    }

    long start = System.currentTimeMillis();
    try {
        Result result = doSomething(param);
        long cost = System.currentTimeMillis() - start;

        // 业务请求成功
        if (log.isInfoEnabled()) {
            log.info("业务请求成功|biz request success traceId={} bizType={} bizId={} userId={} resultCode={} costMs={}",
                    traceId, bizType, bizId, userId, result.getCode(), cost);
        }
        return result;
    } catch (Exception e) {
        long cost = System.currentTimeMillis() - start;

        // 业务请求失败：必须带 e 输出堆栈
        log.error("业务请求失败|biz request failed traceId={} bizType={} bizId={} userId={} costMs={} error={}",
                traceId, bizType, bizId, userId, cost, e.getMessage(), e);
        throw e;
    }
}
